# Renting Particulares España

Tabla de cuotas de renting para particulares en España (marca, modelo, versión, combustible, €/mes IVA incluido, meses y km/año), con filtros y ordenación.

- `index.html`: la página.
- `data.json`: ofertas, fotos y fecha de actualización. Se regenera con `build_data.py`.
- Fuentes de precios: Idoneo, Renting Finders, Coches.com y Ayvens. Precios "desde", sin entrada; confírmalos en la web de origen.
- Fotos: Wikimedia Commons, con autor y licencia en cada imagen.
